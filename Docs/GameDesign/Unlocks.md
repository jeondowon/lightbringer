# 병정·스킬 해금표

작성: 2026-10-29. '초안' 칸이 현재 코드(`UnitCatalog.UnlockStages`, `SkillCatalog.RewardFor`)에 반영된 값이다. '이전 코드'는 2026-10-29 이전 값이다.

숫자는 모두 **처음 쓸 수 있는 스테이지**다. 검병·빛 광선·충격파는 처음부터 쓸 수 있고, 나머지는 바로 앞 스테이지의 첫 클리어 보상으로 열린다. (예: 궁수 3 = 스테이지 2 보상)
수정할 때는 '초안' 칸의 숫자를 바꾸고 위 두 코드 표도 함께 고친다. 줄은 초안 스테이지 순서로 정렬했다.
초안에서 새 병정·스킬을 얻지 못하는 스테이지는 '초안' 칸에 스테이지 번호만 있는 빈 줄로 남겨 두었다.

## 관련 규칙
- 새 적은 대응 수단과 같은 스테이지이거나 그보다 먼저 나온다. 새 아군·기술과 같은 스테이지에 나와도 된다 ([Campaign.md](Campaign.md) '적 등장 순서').
- 군집병 제한은 마법사와 같은 12스테이지에 푼다.
- 병정 해금 순서는 `UnitKind` 순서(검병 → 궁수 → 방패병 → 창병 → 사제 → 마법사 → 기사 → 드래곤)와 같아야 한다. 해금된 병정 수로 숫자 키와 카드 순서를 정하기 때문이다.
- 1막 보스(8)는 룬 결계를 주고, 2막 보스(16)는 빛의 조각만 준다.
