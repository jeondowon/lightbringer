# 남은 작업

기준일: 2026-10-14 · 현재 구현 범위는 `README.md`, 기술 상세는 `GameDesign/Skills.md` 참고.
완료한 항목은 지우지 말고 `[x]`로 바꾼 뒤 날짜를 적는다.
2막·3막(9~24스테이지)과 마왕 최종전은 이미 구현돼 있어, 아래는 그 위에서 다듬을 일이다. 코드만 보고 정리한 것이라 플레이 확인이 필요하다.

## 게임플레이·밸런스

- [ ] **직접 플레이 밸런스 조정**
  - Food 속도·비용
  - 병종 역할
  - 기사 돌격: 즉사로 넉백이 안 보이는 문제
  - 지상 드래곤 생존력
  - 보스·기술 수치
- [ ] **경험치 곡선 재조정**: Lv16 이후 필요 경험치는 추정치(×1.12). 2·3막 실제 획득량에 맞추고, 목표 레벨(16스테이지 Lv25, 24스테이지 Lv30)과 "처음 클리어만으로는 2~3 낮다"는 원칙이 지켜지는지 확인.
- [ ] **재도전 보상 확인**: 빛의 조각 공식 `100 + 50 × 스테이지`가 24스테이지까지 맞는지.

## 2막·3막 개선

- [ ] **막별 정체성**: 17~23이 서로 다르게 느껴지는지 점검. 지금은 Path 수·경로·환경 테마 위주이고, 지형 기믹이나 적 조합 차이는 약할 수 있음 (`Campaign.md` 주의점).
- [ ] **16스테이지 군주**: 손상된 갑주 전용 외형과 추가 연계 패턴이 없음 (기존 모델 재사용).
- [ ] **24스테이지 최종전 점검**: 두 보스 큰 공격의 번갈아 사용, 경고 중첩 여부, 근접 병력의 마왕(핵) 기여, 대규모 전투 성능.
- [ ] **드래곤 해금 시점**: 문서 안은 17~20 구간 검토. 지금은 8스테이지 테스트 해금 그대로.
- [ ] **엔딩**: 24스테이지 마지막 대화, 봉화 복원, 군주·마왕의 결말은 "별도 확정" 상태.
