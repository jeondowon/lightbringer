# Lightbringer UI 스타일: 그림책 그림체에 맞춘 글꼴·컴포넌트

작성: 2026-10-13 · 상태: **1차 적용 완료 (사용자 확인 대기)**

## 1. 결정과 범위

Lightbringer의 그림체는 **프롤로그와 타이틀 화면의 그림책 그림체**다.
게임의 **UI(글꼴과 UI를 이루는 컴포넌트)**를 이 그림체에 어울리는 스타일로 통일한다.

**바꾸는 것**
- 글꼴: 제목, 본문, 숫자
- UI 컴포넌트:
  - 패널, 카드, 버튼, 탭, 테두리, 구분선
  - 게이지(HP/MP/식량/경험치), 배지·태그, 키 안내
  - 모달 안내창
- 적용 화면:
  - 전투 준비(영웅·병력)
  - 승리/패배 안내창, 일시정지, 레벨업, 유닛 강화
  - 전투 HUD(미니맵 틀, 아군 소환 메뉴, 영웅 상태창, 기술 바, 본진 체력, 진로 표시)
  - 타이틀·프롤로그·지도 화면의 버튼과 라벨

**바꾸지 않는 것**
- 3D 전투 화면의 그림체, 조명, 후처리
- 캠페인 지도 그림 (`CampaignAtlas_*.png`)
- 타이틀·프롤로그 그림
- 스킬 아이콘 (`Assets/UI/Art/Skill_*.png`): 마음에 들어서 그대로 쓴다

## 2. 진단: 지금 UI는 그림책과 결이 다르다

비교 캡처:
- 대상: `PreparationPreview.png`, `TroopsPreview.png`, `ResultPreview.png`, `DefeatPreview.png`, `BattleHudPreview.png`, `PausePreview.png`, `LevelUpPreview.png`

| 요소 | 지금 | 문제 |
|---|---|---|
| 패널·카드 | 짙은 네이비 그라데이션 + 매끈한 금테 + 깎인 모서리 | 모바일 MMO·가챠 느낌. 그림책의 종이·잉크 질감이 없음 |
| 버튼 | 광택 있는 금속 브라운 알약 + 금테 | 반짝이는 금속 질감이 그림책과 충돌 |
| 승리/패배 | 빛줄기 후광 + 월계수 메달 + 네온 글로우 큰 글자 | 모바일 게임 결과창 문법 |
| 게이지 | 채도 높은 빨강/파랑/노랑 막대 | 그림책 팔레트에 없는 원색 |
| 글꼴 | 굵은 고딕(본문·제목 모두), 영문만 Cinzel | 로고의 각인 세리프 감성과 단절. 한글 제목에 개성이 없음 |
| 전투 HUD | 양피지 미니맵 + 금테 네이비 소환 메뉴 + 가챠풍 초상 틀 | 한 화면에 UI 언어가 2~3종 섞임 |
| 타이틀·프롤로그 버튼 | 단색 사각형 | 그림 위에서 시스템 기본 UI처럼 겉돎 |

현재 글꼴 자원: `Assets/UI/Fonts/Cinzel.ttf`(영문 세리프), `NanumGothic-Regular.ttf`(한글 고딕).

## 3. 기준 그림체에서 가져올 것

기준 이미지:
- `Assets/Art/UI/MainMenu/Title_LastLight_Storybook_v2.png`
- `Docs/ArtReference/Prologue/*_Storybook_*.png`
- `Assets/Art/UI/MainMenu/Lightbringer_Storybook_Logo_v1.png`

UI로 옮길 특징:
- **잉크 윤곽선:** 형태를 선으로 잡는다. 기계적으로 완벽한 선보다 살짝 흔들리는 손그림 선을 쓴다.
- **무광 과슈 + 종이 그레인:** 면은 탁하고 무광이다. 거친 종이 질감이 깔린다. 광택, 유리 반사, 금속 하이라이트는 쓰지 않는다.
- **어둠 속 국소적인 금빛:** 화면 대부분은 어둡게 두고, 금빛은 빛이 있는 곳에만 쓴다. → UI에서도 **금은 강조(선택·활성·보상·빛)에만** 쓴다.
- **로고:** 아이보리 면 + 바랜 금 테두리 + 잉크 윤곽의 각인 세리프, 그리고 하단의 가는 덩굴 장식과 4각 별.

### 팔레트 (기준 이미지에서 추출)

| 역할 | 색 | UI 용도 |
|---|---|---|
| 잉크 밤하늘 | `#1C1F2A` `#262731` | 패널 바탕, 모달 배경 |
| 슬레이트 블루그레이 | `#33343C` `#565863` `#575F73` | 비활성 카드, 구분선, 보조 텍스트 |
| 흙·가죽 브라운 | `#3C2C1F` `#3E2F27` `#765B4A` | 버튼 바탕, 게이지 빈 칸 |
| 바랜 양피지 | `#74685E` `#B59672` | 밝은 종이 면(미니맵, 카드 안쪽), 본문 글자색 후보 |
| 빛의 금색 | `#D19F5A` `#DCB074` `#ECC489` | 선택 테두리, 강조 글자, 보상 |
| 빛 하이라이트 | `#F8D294` | 가장 중요한 강조점에만 |
| 적·위험 | 탁한 진홍~보라 (타이틀 지평선) | 적 정보, 패배, 경고 |

게이지 색도 이 팔레트 안에서 탁하게 쓴다. 원색 빨강·파랑은 쓰지 않는다.
- HP: 탁한 진홍
- MP: 슬레이트 청색
- 식량: 금빛 호박색

## 4. UI 컴포넌트 규칙

| 컴포넌트 | 새 스타일 |
|---|---|
| 패널 | 잉크 밤색 종이 면(그레인) + 손그림 잉크 이중선 테두리. 모서리는 작은 잉크 꺾쇠나 덩굴 장식. 깎인 금속 모서리는 쓰지 않는다 |
| 카드 | 패널과 같은 재질. 선택하면 금빛 잉크선과 은은한 안쪽 번짐. 잠긴 카드는 슬레이트로 바래게 |
| 주 버튼 | 양피지나 가죽 띠 위에 세리프 글자. 활성일 때만 금 테두리. 금속 광택은 없다 |
| 보조 버튼 | 잉크 테두리만 있는 투명 띠 |
| 구분선 | 가는 잉크선 + 가운데 4각 별(로고 모티프) |
| 게이지 | 잉크 테두리 안의 무광 채움. 끝단은 붓 자국처럼 처리 |
| 배지·키 안내 | 작은 잉크 원·사각 도장. 글자는 양피지색 |
| 모달 (승리/패배/일시정지) | 그림책 한 페이지처럼: 가운데 종이 면 + 세리프 제목 + 덩굴 장식 |
| 모달: 승리 | 봉화 불빛을 작은 금빛 삽화로 넣는다 |
| 모달: 패배 | 꺼진 봉화와 진홍 잉크 번짐 |
| 모달 공통 | 빛줄기 후광, 월계수 메달, 네온 글자는 쓰지 않는다 |
| 아이콘 | 스킬 아이콘 형식(금테 메달리온 + 안쪽 페인터리 그림)을 표준으로 삼는다 |
| 미니맵 | 양피지 지도 방향은 유지한다. 틀과 라벨을 위 패널 규칙에 맞춘다 |

전투 HUD에서는 3D 위 가독성이 우선이다. 바탕을 진한 잉크색 반투명으로 두고, 테두리·장식 어휘만 공유한다. 화면 가장자리에 붙이고 크기를 지금보다 줄인다.

## 5. 글꼴

| 용도 | 방향 | 후보 (모두 OFL 계열 확인 필요) |
|---|---|---|
| 한글 제목 | 붓·명조 계열. 로고의 각인 세리프와 어울리는 무게 | 마루 부리(Maru Buri), 나눔명조, 본명조(Noto Serif KR) |
| 한글 본문 | 작은 크기에서도 읽혀야 함. 명조가 작은 크기에서 약하면 고딕 유지 | 나눔고딕(현행) 또는 마루 부리 Regular |
| 영문 장식 | 현행 유지 | Cinzel |
| 숫자 (게이지·비용) | 세리프 계열 고정폭 숫자 | 제목 서체의 숫자 또는 Cinzel |

글꼴 파일은 `Assets/UI/Fonts/`에 넣고 라이선스 파일을 함께 둔다(현행 방식).

## 6. 구현 방식

- UI 장식 텍스처는 `UiChromePainter*.cs`가 그린다. 위치는 `Assets/Scripts/Editor`이고, 결과물은 `Assets/UI/Art/Chrome`에 저장된다.
  - 그림책 세트(종이 그레인, 잉크 테두리, 덩굴 모서리, 별 구분선, 붓 게이지)를 여기에 추가하거나 기존 것을 교체한다.
  - C# 5 문법을 유지해서 PowerShell 미리보기로 빠르게 반복한다.
- 화면 코드: `PreparationView.cs`, `UnitUpgradeView.cs`, `ResultView.cs`, `PauseView.cs`, `LevelUpView.cs`, `BattleHudView.cs`, `HudWidgets.cs`, `BattleMinimap.cs`, `CampaignMapView.cs`, `TitleView.cs`, `PrologueView.cs`
- 색과 글꼴은 한곳(공용 테마)에 모아서 화면마다 따로 정하지 않게 한다.
- 각 단계마다 미리보기 캡처로 확인한다.

## 7. 진행 순서

1. **시안:** 컴포넌트 세트(패널·카드·버튼·구분선·게이지)와 글꼴 후보를 만든다. 승리 안내창 하나에 적용해서 캡처로 비교한다.
2. **전투 준비:** 영웅 준비 → 병력 준비 순으로 적용한다.
3. **안내창:** 승리/패배, 일시정지, 레벨업, 유닛 강화.
4. **전투 HUD:** 소환 메뉴, 영웅 상태창, 기술 바, 미니맵 틀, 상단 본진·진로 표시, 키 안내.
5. **나머지:** 타이틀·프롤로그·지도의 버튼과 라벨.

- 승리/패배: 봉화 엠블럼을 제거했다. 엠블럼 여백이 빠지면서 안내창이 자기 높이의 94%로 눌리던 문제는 `max-height: 100%`로 고쳤다.

**3차 수정 (2026-10-13)**
- 공세·진로 칩을 종이 태그(`Ui_Tag`, `Ui_TagActive`, `Ui_TagAlert`)로 바꿨다. 위험 상태가 선택 상태보다 우선한다.
- 방패·해골·교차한 칼 아이콘을 잉크 윤곽 + 과슈 채색(`Ui_Icon*`)으로 새로 그렸다. 예전 광택 아이콘(`Hud_Icon*`)과 생성 코드는 삭제했다.
- 인장 문구는 고유어 서수로 쓴다(`BattleHudView.StageSealText`). 예: "여덟 번째 / 봉화"
- 본진 체력바를 330×20px로 키웠다.
- 진로 카드: 번호를 미니맵의 진로 표식과 같은 양피지 원으로 바꿨다(소환 진로는 붉은 인장). 아군·적 수 사이에는 줄다리기 게이지와 가운데 기준선을 넣었다. 글자는 추가하지 않았다.
