# Lightbringer — 작업 로드맵

기준 문서: `Docs/GameDesign/3D_Paladog_Project_Handoff_v0.3.docx`
작성: 2026-10-02 / 하나씩 단계별로 진행하고, 끝난 항목은 체크한다.

## 현재 상태 요약

- 코어 루프(이동 · Food · 소환 · Path 진격 · 전투 · 오라 · 본진 승리) 구현 완료
- 캠페인 8 스테이지, Mana/장비, EXP 레벨업 3택1 영구 성장, 저장 구현 완료
- 3D 모델 적용: 여성 영웅, 검사, 궁수, 방패병(정적), 기사+말(정적), 드래곤(리깅)
- 남은 병종 3D: 창병, 사제, 마법사 (별도 트랙)

## Step 1. 적 진영 확장 ⬅ 현재

병종 선택이 의미 있으려면 적에게 역할 차이가 있어야 한다.
현재 적은 `Enemy Raider` / `Enemy Archer` 2종, 프리미티브 실루엣 (`Assets/Scripts/Core/EnemyWaveSpawner.cs`).

- [x] 적 역할 표 확정 (아래 표)
- [x] `EnemyCatalog` 데이터 분리 (`Assets/Scripts/Units/EnemyCatalog.cs`)
- [x] `EnemyWaveSpawner`를 스테이지별 웨이브 구성 데이터 기반으로 변경 (막힌 스폰은 버리지 않고 대기열)
- [x] 역할별 실루엣 구분 (`SilhouetteFactory`: Swarmling / Brute / Shaman / Warlord)
- [x] 보스 스테이지 — Stage 8: Warlord가 마지막 웨이브와 함께 중앙 전선으로 진격, 처치 전까지 적 본진 방어막
- [x] 창병 Heavy 보너스 (Heavy 대상 2배 피해)
- [x] 기사 돌격 (5 m 이상 이동 후 첫 타격 2.5배 + 주변 1.8 m 타격 + 비Heavy 적 1.5 m 밀쳐냄), 기사 체력 120→170 / 공격력 24→32
  - [ ] **보류: 돌격 밸런스.** Stage 7 적 체력(Raider 60, Archer 46, Shaman 48, Swarmling 22)이 돌격 피해 80보다 낮아 대부분 즉사 → 밀쳐내기가 안 보임. Brute(216)는 Heavy라 밀리지 않음. 배율 조정 또는 피해 대신 기절/넉백 위주로 재설계 검토. 넉백 연출은 Step 3에서.
- [ ] 다른 병종도 기획 의도와 코드가 맞는지 점검 (사제, 마법사, 드래곤 등)
- [x] 검증 Editor 스크립트 갱신 (`EnemyRosterValidation.cs` 신규, 전체 266 checks PASS)
- [ ] 플레이테스트 후 수치 밸런싱 (특히 Stage 8 Warlord 체력/공격력)
- [ ] 적 3D 비주얼 방향 정리 (타락한 정령 / 괴물 / 언데드) — 모델 작업은 아트 트랙으로

| 적 | 역할 | 등장 | 카운터 아군 |
|---|---|---|---|
| Raider | 기본 근접 | 1~ | 검사 |
| Archer | 후방 원거리 | 2~ | 방패병, 궁수 |
| Swarmling | 저체력·고속 물량 | 3~ | 마법사 광역 |
| Brute (Heavy) | 고체력·저속 탱커 | 4~ | 창병 |
| Shaman | 주변 적 회복 | 5~ | 궁수·마법사로 후열 처리 |
| Warlord (Heavy, 보스) | 최종 목표 | 8 | 영웅 + 전 병력 |
