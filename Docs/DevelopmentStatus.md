# Lightbringer 개발 현황 / 환경 이전

기준: 2026-10-12, Unity 6000.3.20f1 + URP. 구현 여부와 최종 품질 검증은 구분한다.

## 2026-10-14 — 2막 추가

- 배경 기준은 지도 아트 프롬프트 `CampaignAtlas_Acts_v1/v2.prompt.txt`다. 9~11 옛 용사 유적 → 12~14 점령된 보급 거점 → 15 경비 교량 → 16 군주 성채로 전장을 구성했다. 잿빛 흙·고사목·그루터기·폐허·야적장·마차·강안개를 실제 환경에 생성하며, 최종 환경 모델이 아닌 Greybox다. 15의 얼음은 기술 보상이고 눈/얼음 지형은 없다.
- 플레이 가능 범위를 16스테이지로 확장했다. 9~16에는 각각 다른 경로와 공세 조합이 있으며, 15는 얼음, 16은 운석 마법을 해금한다. 3막은 준비 중이다.
- 16 군주 재대결은 아군을 유지하고 검기 뒤에 예고가 있는 돌진을 연결한다. 전용 등장·퇴각 대사를 사용하며, 모델과 삽화는 기존 에셋을 재사용한다.
- 저장 버전 4로 기존 8스테이지 진행을 이관한다. 8 클리어 기록이 있으면 9를 해금하며 영구 성장과 보유 자원을 유지한다.
- 지도 환경 반영 후 Unity 컴파일, 시스템 검사 581개, 2막 전용 실제 Play 검사 53개 PASS. 전체 Play 검사는 기존 효과음 음량 검사에서 중단됐으며 별개로 남겨 두었다. 전용 검사는 소환·초기 이동과 공세 강제 정리를 통한 진행 검증으로, 자연 플레이 난이도 검증은 아니다.
- 상세 범위와 Editor 실행 방법: `Docs/Validation/ActTwoImplementation.txt`. 아래 과거 구현·검증 기록의 8스테이지 표기는 당시 범위다.

## 현재 구현

- 핵심 루프: 3인칭 영웅 이동/공격, Food 생성, 개별 소환, 신규 병력의 Path 배정, 자동 진격/전투, 오라, 본진 승패.
- 캠페인: 프로토타입 8개 스테이지, 1~3개 Path, 병종 해금, Mana/장비, EXP 및 레벨업 3택1 영구 성장, 저장/불러오기.
- 아군 8종: 검사, 궁수, 방패병, 창병, 사제, 마법사, 기사, 드래곤. 여성 영웅 및 전 병종 모델/리깅 적용.
- 적 6역할: Raider, Archer, Swarmling, Brute, Shaman, Warlord. 8스테이지는 공세 격퇴 후 본진 파괴로 군주 등장 연출과 대화가 시작되며, 군주 격퇴로 승리한다. 이야기상 군주는 퇴각 후 재등장한다. 오로라 충격파와 여섯 특수 공격은 `Docs/GameDesign/BossEncounter.md` 참고.
- 이야기 진행: 8의 등장 대화·퇴각을 프롤로그 방식의 전체 화면 일러스트 각 3장, 총 6장으로 표시한다. 대사에 맞춰 0.35초 교차 페이드로 장면을 바꾼다. 군주 HP 0에서는 전투를 멈추고 퇴각 대사를 보여주며, 마지막 전장 그림과 페이드가 끝난 뒤 승리/클리어 보상을 확정한다. 대화 중 카메라는 전환하지 않는다. 이후 재대결과 최종 군주·마왕 동시전은 `Docs/Audio/GameDesign/CampaignStoryProgression.md`의 기획안이며 현재 구현 범위는 8개다.
- 화면: UI Toolkit 캠페인 지도/출전 준비/전투/레벨업/결과/일시정지 화면, 18장 프롤로그, 미니맵, 체력바, 자원/병종/장비 표시.
- 음악: 전투 및 프롤로그 BGM, 음량 조절, 일시정지·종료 페이드, 게임 내 크레딧. 사용하지 않는 음악 데모와 전용 제작 도구는 제거했다.
- 효과음: 현재 18종/20개 WAV. 사용자 선택 음원은 마법사 Fire Magic, 사제 Healing Magic, 영웅 Light 지팡이 RPG Sword Attack Combo 6, 활 발사 Arrow Swish 03, 화살 명중의 두 번째 타격, 보스 Cinematic Hit, 승리 FX Light, 패배 Medieval Horn이다. 아군 사망에만 여성(궁수·사제·마법사) Grunt와 남성(검사·방패병·창병·기사) Grunt 1을 구분해 연결했다. 일반 피격에는 병력 신음을 재생하지 않는다. 영웅 피격은 Classic Punch Impact로 교체했고, 소환·근접·돌격·화염·보스 경고·버튼·사용 불가 안내를 유지한다. 공통 마법·병력 사망·레벨업은 새 음원 선택 대기 중이다. 전장 20개/UI 4개 풀과 별도 효과음 음량 설정을 사용하며, 버튼 선택음은 사용자 선택 Button Press, 병력 소환음은 Spell Casting으로 교체했다. 출처: Assets/Audio/SoundEffectsNotes.txt.
- 연출: 공격 타이밍, 화살/마법탄, 피격 효과, 드래곤 화염, 회복/오라 축복/본진 효과, 전장 환경 및 셰이더.
- 성능: 군중용 경량 메시 및 LOD, 애니메이션 상태 전환·미니맵·체력바 갱신 비용 절감, 품질 3단계, 자동 품질 하향/해상도 조정, 벤치마크 도구.

## 다음 작업 순서

1. 맥에 동일 Unity 버전과 Git LFS를 설치하고 클론한 뒤 캠페인 실행 및 자동 검증. 대표 전투를 품질 단계별로 측정한다.
2. `Docs/Playtest/PlaytestGuide.md`에 따라 Stage 1~8 실제 플레이. Food 속도/비용, 병종 역할, 기사 돌격, 지상 드래곤 생존력, 보스 난이도, 3개 전선 가독성을 우선 조정한다.
3. 타격/소환/오라/승패 SFX를 추가한다. 전투·프롤로그 BGM은 구현되어 있다.
4. 레인 수 차이를 넘어 Path 형태/지형/환경 테마가 다른 스테이지를 만든다.
5. 적 3D 모델, 장비 등급 보상/강화 여부, 병종 해금 및 드래곤 등장 연출을 정리한다. 남성 영웅은 시스템 안정화 이후다.

## 맥 인수인계

1. 이전 PC에서 원하는 변경을 커밋하고 push한다.
2. Unity Hub 및 Unity 6000.3.20f1을 설치한다. Apple Silicon 맥은 해당 아키텍처 에디터를 사용한다.
3. Git LFS 설치 후 `git lfs install`, 저장소 클론, 클론 폴더에서 `git lfs pull`을 실행한다.
4. Unity Hub에 프로젝트 폴더를 추가하고 패키지 다운로드와 임포트 완료를 기다린다. `Library/`, `Temp/`, `Logs/`, `obj/`는 이전하지 않는다.
5. `Lightbringer > Validate Greybox Systems`, `Lightbringer > Validate Campaign in Play Mode`로 확인한다.
6. `Lightbringer > Prepare and Play Campaign` 또는 `Assets/Scenes/CampaignPrototype.unity`에서 직접 플레이한다. F9는 품질 변경, F10은 성능 표시다.

`AGENTS.md`는 Git에 포함되어 함께 내려받는다. 로컬 도구 설정과 인증 정보는 저장소에 추가하지 않는다.
기존 캠페인 진행을 유지하려면 `Application.persistentDataPath/Lightbringer/`의 저장 파일도 별도로 이전해야 한다. 클론만으로는 개인 세이브와 플레이테스트 기록이 이동하지 않는다.

기획서 v0.3 이후 결정으로 로드맵에 기록된 예외는 골드 제거와 드래곤 지상 유닛화다. 이 문서는 추가 설계 변경을 도입하지 않는다.
