측정: 2026-10-12 17:28:12 UTC · 24개 WAV. 수치는 dBFS이며 0에 가까울수록 큽니다. 스피커에서 나오는 실제 dB SPL이나 LUFS 측정값은 아닙니다.

파일 피크는 한 순간의 최대값, 전체 RMS는 무음과 잔향을 포함한 평균입니다. 최대 100ms RMS는 연속 0.1초 중 가장 큰 구간의 평균으로, 길이가 다른 짧은 효과음을 비교하는 보조 지표입니다. 음색에 따른 체감 차이는 청취로 확인해야 합니다.

모든 효과음을 최대 100ms RMS −20 dBFS로 보정하고, 순간 피크는 −1 dBFS 이하로 제한했습니다. 기존 효과음별 추가 감쇠를 제거하여 게임 슬라이더가 재생 음량을 직접 조절합니다.

게임 예상치는 기본 효과음 설정 70%를 반영했습니다. 사용자 저장 설정·거리 감쇠·동시 재생·오디오 출력 장치는 반영하지 않았습니다. 전체 파일 평균은 잔향과 길이에 따라 다릅니다.
