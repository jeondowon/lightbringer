Lightbringer 프롤로그 — 구현 및 장면 순서

사용자가 지정한 18장 순서를 고정한다. 파일명 정렬로 순서를 추측하지 않는다.
03은 언덕의 봉화 v3, 03(V5)는 마을 광장 v5로 서로 다른 장면이다.
07은 LightStrikes v2, 뒤의 07(ForgottenBeacon)은 봉화 앞 영웅 v1이다.
05는 현재 남아 있는 ForgottenPromise v1을 사용한다.
옛 기사가 Warlord가 되었다는 설정은 이 시점에 자막으로 공개하지 않는다.

실행
- Assets/Scenes/CampaignPrototype.unity를 열고 Play.
- 최초 실행 시 프롤로그. 감상 또는 건너뛰기 완료 후 캠페인 지도.
- 지도에서 '프롤로그 다시 보기'로 언제든 재생 가능.
- 프롤로그 감상 여부는 PlayerPrefs Lightbringer.PrologueViewed.v1에 저장한다.
- 별도 테스트 세션은 이 값을 쓰지 않으며 캠페인 저장 파일은 수정하지 않는다.
- 이미지 클릭 / Space / 오른쪽 화살표: 다음 자막, 마지막 자막에서는 다음 그림.
- 왼쪽 화살표 / 이전 버튼: 이전 자막. 장면 경계에서는 이전 그림의 마지막 자막.
- Esc / 건너뛰기: 부드럽게 종료하고 지도 복귀. 음악 정보가 열려 있으면 Esc는 먼저 이를 닫음.
- 자동 넘김은 기본 꺼짐. 켜면 자막 길이에 맞춰 넘기며 음악 정보 창에서는 대기.
- 첫 진입 및 장면 전환은 0.65초 페이드. 원본 그림은 비율 유지, 화면 비율에 따른 여백 처리.
- 한국어 자막은 번들 NanumGothic 폰트로 표시한다. 녹음 내레이션은 아직 없다.
- 기존 Legionnaire 배경음악 스트리밍/반복, 진입·종료 음량 페이드. 음악 정보에서 라이선스/음량 확인.
- 프롤로그 중에는 지도 입력과 전투 시작을 막고, 끝나면 전투 준비 흐름으로 복귀한다.

에셋 및 유지보수
- 런타임: Assets/UI/Resources/Prologue/Sequence.asset (18장, 자막, 음악 참조).
- 그림: Assets/UI/Prologue/*.png. Docs의 원본은 유지한다.
- Lightbringer > Prologue > Build and Validate: 원본 18장을 복사/임포트하고 기본 자막과 순서를 재생성한다.
- 기본 자막/선정 버전은 Assets/Scripts/Editor/PrologueSetup.cs에서 관리한다.
- Sequence Inspector에서 직접 수정한 내용은 Build 실행 시 기본값으로 교체된다.
- Lightbringer > Prologue > Validate: 순서/자막/이동/자동 넘김/완주/건너뛰기/재생/전투 진입 검증.
- Lightbringer > Prologue > Capture Preview: Docs/Validation/ProloguePreview.png 생성.

장면과 자막

검증 결과
- Unity Editor 컴파일 및 PrologueValidation 53개 항목 PASS.
- 기존 GreyboxValidation 328개 항목 PASS.
- 1920x1080 및 1280x1024 미리보기에서 한국어 자막, 조작 UI, 그림 비율 확인.
- 녹음 음성 및 실제 플레이어 빌드 검증은 이번 작업에 포함하지 않음.
