# 캠페인 진행안 — 되돌아오는 어둠의 군주

2026-10-12. 사용자 확정 방향: 8스테이지의 어둠의 군주는 죽지 않고 물러난다. 이후 보스전에서 다시 등장하며, 마지막에는 어둠의 군주와 마왕을 함께 상대한다.

군주는 봉인된 존재가 아니다. 성채가 함락되자 직접 전장에 나타나 영웅의 진격을 막는다. 성채 붕괴 직후 퍼지는 오로라 에너지파는 군주의 공격이며, 봉인 해제 현상이 아니다.

아래의 **24스테이지 / 3장 전체 구성은 제안**이다. 2026-10-14 사용자 요청으로 2막 9~16을 구현해 현재 플레이 가능한 범위는 16스테이지다. 16에서는 옛 용사의 정체를 대사로 드러내며, 검기 후 돌진 연계를 사용한다. 기존 모델·삽화를 재사용하고 손상된 갑주 전용 외형은 아직 없다. 17~24와 최종 동시전은 미구현이다. 기본 전투는 영웅 직접 조작, 병력 개별 소환과 자동 진격, 봉화 탈환을 유지한다. 구현 범위는 `../../Validation/ActTwoImplementation.txt` 참고.

## 진행과 보상

| 구간 | 이야기와 전장 | 플레이의 변화 / 성과 |
|---|---|---|
| 1~3 · 꺼진 변경 | 작은 거점에서 봉화를 다시 밝히며 지휘관과 병사들의 관계를 쌓는다. | 한 전선에서 이동·소환·오라·장비 마법을 익힌다. |
| 4~7 · 검은 성채로 | 군주의 군세가 지키는 거점들을 돌파한다. 탈환한 지역이 서로 이어진다. | 둘 이상의 Path와 적 조합으로 지원할 전선 선택을 요구한다. 7에서 성채까지 진입로를 확보한다. |
| 8 · 첫 격퇴 | 정규 공세 종료 → 적 본진 파괴 → 오로라 파동으로 아군 병력 전멸 → 군주 등장·대화 → 결투 → 군주 퇴각. | 충격적인 첫 대면이지만 실제로 승리한다. 군주는 부상을 입고 지역 지배권을 잃으며, 영웅은 봉화를 되찾는다. |
| 9~12 · 옛 기사의 흔적 | 전쟁의 피해를 수습하며 다음 봉화로 나아간다. 옛 빛의 기사와 군주의 관련성을 암시하는 흔적을 발견한다. | 달라진 Path 형태와 적 조합을 도입한다. 이미 되찾은 봉화를 빼앗거나 성장을 초기화하지 않는다. |
| 13~15 · 군주의 반격 | 군주가 마왕의 귀환을 위해 시간을 벌며 진격을 막는다. 영웅은 군주의 거점과 보급로를 끊는다. | 익힌 병종의 조합과 영웅 지원 능력을 시험한다. 15에서 두 번째 군주전의 진입로를 확보한다. |
| 16 · 두 번째 격퇴 | 군주와 재대결. 옛 기사가 군주가 되었다는 기존 설정을 여기서 드러내는 안. 영웅은 군주를 다시 몰아내고 마왕의 성으로 가는 길을 연다. | 군주의 무기나 갑주를 손상시키는 명확한 승리. 군주는 생존을 위해 퇴각한다. ‘일부러 져 주었다’는 대사로 플레이어의 승리를 무효화하지 않는다. |
| 17~20 · 마왕의 영역 | 봉화의 빛을 이어 마왕의 영역으로 진입한다. 군주는 뒤에서 전선을 지휘한다. | 후반 병력과 강화의 효용을 보여주는 큰 전장. 드래곤의 정식 해금·등장 시점도 이 구간에서 검토한다. 현재 8스테이지 테스트 해금은 그대로 둔다. |
| 21~23 · 최후의 진격 | 마왕의 성을 지탱하는 외곽 거점을 무너뜨린다. 23에서 마지막 진입로와 병력 집결지를 확보한다. | 각 거점 탈환은 최종전 접근이라는 실제 성과를 남긴다. 새로운 조작 체계 대신 기존 전투의 종합 시험으로 구성한다. |
| 24 · 두 어둠 | 어둠의 군주와 마왕이 함께 출전한다. | 두 보스가 모두 쓰러져야 최종 승리. 마지막 대화와 봉화 복원으로 캠페인을 마무리한다. 군주의 최후와 마왕의 결말은 별도 확정한다. |

프롤로그의 ‘옛 기사와 마왕이 빛 속에서 사라졌다’는 사건을 유지한다. 군주의 정체는 프롤로그나 8스테이지에서 직접 공개하지 않는다. 각 지역의 짧은 대사·환경 흔적을 먼저 쌓아 16의 공개가 갑작스럽지 않게 한다.

## 같은 보스가 돌아와도 다른 전투가 되도록

- **8: 기본 언어를 배운다.** 현재 구현된 근접 공격과 초승달 검기·휩쓸기·낙뢰·돌진·충격파·증원을 사용한다. 예고와 회피 방향을 충분히 보여 준다.
- **16: 패턴을 연결한다.** 초승달 이후 시간차 돌진, 위치를 순서대로 찍는 낙뢰 등 기존 공격을 조합한다. 체력만 올리지 않고 연계 순서를 바꾼다. 위험 구역과 회피 가능한 틈은 남긴다.
- **24: 두 보스의 역할을 나눈다.** 군주는 검기·근접·돌진으로 압박하고 마왕은 넓은 장판·암흑 마법·소환을 맡는다. 둘은 처음부터 함께 활동하되, 큰 공격은 번갈아 사용하도록 조율한다. 피할 수 없는 경고 중첩을 막는다.
- 최종전은 별도 HP 두 개와 자유로운 처치 순서를 사용한다. 하나를 먼저 쓰러뜨리면 남은 보스의 연계가 끊긴다. 남은 보스의 반격 패턴은 한 가지 강화하되 HP를 전부 회복시키지 않는다.
- 8의 병력 전멸은 첫 등장에만 사용한다. 재등장마다 같은 강제 전멸을 반복하지 않는다. 최종전에서도 자동 진격 병력이 함께 싸우며, 오라 지원과 재소환이 의미를 가진다.

## 8스테이지 대사 — 이번에 코드에 반영

등장 직후:

1. **어둠의 군주:** “꺼진 봉화들을 밝히고 다닌 자가 너였나. 네 진격도 여기까지다.”
2. **빛의 지휘관:** “내 병사들에게 무슨 짓을…! 네가 이 어둠의 주인인가?”
3. **어둠의 군주:** “나는 그분의 검이다. 마왕께 이르는 길은 여기서 끝난다.”
4. **빛의 지휘관:** “누가 네 뒤에 있든, 우린 멈추지 않아. 쓰러진 이들을 위해서라도 이 땅을 되찾겠다.”

승리 결과에는 **군주가 물러났으며 봉화에 빛이 돌아온다**고 표시한다. 군주의 말: “이것으로 끝이라 생각하지 마라. 우리는 다시 만날 것이다.” 최초 장비 보상과 재도전 보상 안내는 유지한다. 목표는 ‘처치’에서 ‘격퇴’로 바꾼다.

## 다음 구현 순서

1. **8스테이지 퇴각 연출 반영 (2026-10-13):** 사용자 요청에 따라 프롤로그처럼 정지 일러스트로 전달한다. HP 0 → 균열로 물러나는 그림과 군주·영웅 대사 → 1.2초 페이드 → 승리/클리어 보상 순서다. 등장 대화도 대면 그림을 사용하며 대화 중 카메라 전환을 없앴다. 퇴각 중 전투·소환·레벨업 창은 보류한다. 별도의 실시간 모델 퇴각 애니메이션은 사용하지 않는다.
2. **2막 제작 반영 (2026-10-14):** 9~16의 이름·작전 설명·경로·공세 수를 CampaignStages로 분리했다. 전용 적 조합, 지도 연결과 버전 4 저장 이관을 함께 적용했다.
3. **두 번째 군주전 반영 (2026-10-14):** 아군 유지, 검기→예고 돌진, 정체 공개와 퇴각 대사를 구현했다. 기존 모델과 삽화를 사용하며, 전용 외형 및 추가 연계는 후속 작업이다.
4. **최종 동시전:** 마왕 별도 AI, 두 보스의 공격 조율, 복수 보스 HUD와 승리 조건을 만든다. 현재의 단일 보스 사망 승리 조건은 이 단계에서 확장한다.

구현된 첫 군주전의 수치와 기술 설명은 [BossEncounter.md](BossEncounter.md)를 참고한다.
