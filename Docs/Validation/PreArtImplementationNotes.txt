Lightbringer: Art Pass 전 구현 인수인계

실행
- Unity 메뉴: Lightbringer > Prepare and Play Campaign
- 또는 Assets/Scenes/CampaignPrototype.unity를 열고 Play.
- 이전 Greybox 씬은 유지된다. 새 캠페인 씬은 준비 화면에서 시작한다.
- 조작: WASD 이동, 마우스 시점(상하 -35~75도), 휠 줌, 1~8 해당 병종 즉시 소환, F 마지막 병종 재소환,
  Tab 이후 소환 병력의 Path 순환 변경, LMB/Q/E 장비 슬롯 사용, Esc 커서 해제.
- 패시브 반지를 넣은 슬롯은 직접 시전하지 않는다. 장비는 준비 화면에서만 변경한다.

기획 대응
- 개별 병사 선택/명령, 집결, 병종 덱 제한은 없다.
- 병사는 소환 때 받은 Path를 유지한다. 경로 선택은 새 병사에게만 적용된다.
- 8개 프로토타입 스테이지. 1~2: 1 Path, 3~5: 2 Paths, 6~8: 3 Paths.
- 첫 클리어마다 다음 스테이지와 다음 병종이 영구 해금된다. 8번째 스테이지 전에 Dragon이 해금된다.
- 병종: 검사, 궁수, 방패병, 창병, 사제, 마법사, 기사, 드래곤.
  원거리/방어/회복/광역/이동속도/비행 등으로 프로토타입 역할을 구분했다.
- 영웅: 체력, 직접 공격, Mana, 회복/광역 지팡이, 3개 장비 슬롯, 패시브 반지, 오라.
- EXP 레벨업은 서로 다른 3개 영구 성장 중 하나를 선택한다.
  전투만 일시정지하며 여러 레벨의 선택 대기열과 이미 제시된 선택지도 저장된다.
- 성장 항목: 오라 크기, Food 생산, Mana 회복, Food/Mana 최대치,
  소환 비용, 오라 공격 보너스, 영웅 위력, 영웅 체력.
- 승리: 적 본진 파괴. 패배: 영웅 사망. 결과 화면에서 준비 화면으로 복귀한다.
- 첫 클리어 보상: 골드와 장비 획득/레벨 상승. 중복 첫 클리어 보상은 차단된다.
  장비는 별도 강화 비용 시스템 없이 더 높은 등급의 보상으로 갱신한다.
- 패배해도 영구 성장과 장비는 유지된다. 전투의 현재 HP/Food/Mana와 병력은 새 전투에서 초기화된다.

저장
- 경로: Application.persistentDataPath/Lightbringer/campaign-v1.json
- JSON 교체 저장과 .bak 백업. 손상된 원본은 복구 시 별도 보존한다.
- 본 저장과 백업이 모두 잘못된 경우 자동으로 덮어쓰지 않고 화면에 오류를 표시한다.
- 성장 선택/장비 선택/승패는 즉시 저장하며, 일반 EXP는 2초마다 및 종료 시 저장한다.
- 테스트는 메모리 프로필과 고유한 임시 테스트 파일만 사용한다. 실제 플레이 저장을 수정하지 않는다.

성능 및 전선 표시
- 유닛 적 탐색 주기 분산, 동적으로 늘어나는 재사용 물리 검색 버퍼.
- 군중 이동 30Hz 분산, 정지 유닛의 불필요한 CharacterController.Move 생략,
  근처 병력에 대한 자동 간격 조정. 영웅은 프레임별 이동을 유지한다.
- 경로 색상/선택 강조, 전선별 병력 수, 가까운 부상 병력 체력 표시(최대 48개), 줌/카메라 장애물 회피.
- 사용자 조작 기반 진형이나 집결 명령은 추가하지 않았다.

검증 재실행
- Lightbringer > Validate Greybox Systems: 기존 기능 + Core Loop + 캠페인 + 100/300명 물리 시뮬레이션.
- Lightbringer > Validate Campaign in Play Mode: 격리된 테스트 씬에서 실제 프레임 진행과 렌더링 검사.
  완료 후 원래 편집 씬으로 복귀한다. 준비 화면/전투/승리/3개 전선/300명 캡처도 생성한다.
- 결과: GreyboxChecks.txt, CombatScaleChecks.txt, CampaignPlayChecks.txt 및 이 폴더의 PNG.

범위와 한계
- 수치, 경로 배치, 적 웨이브, 보상은 변경 가능한 프로토타입 밸런스다.
- 8개 스테이지는 기능과 해금 루프를 검증하는 평면 그레이박스 구성이다.
  최종 지형/보스/스테이지 콘텐츠 다양화는 이후 로드맵 작업이다.
- 원거리 공격은 즉시 판정, 드래곤은 평면 전장 위 비행 프로토타입이다.
- 최종 여성/남성 모델, 애니메이션, 투사체 연출, 고품질 VFX, 사운드와 최종 HUD는 미착수다.
- 성능 수치는 이 Windows Unity Editor의 프리미티브 전장 측정값이다.
  최종 아트 적용 후의 성능, 독립 실행 빌드, macOS 실행 및 주관적 재미/밸런스는 보증하지 않는다.

주요 코드 위치
- Core/: 캠페인 세션, 전장 생성, 승패, 적 웨이브, 전투 일시정지.
- Progression/: 영구 성장/해금/장비 소유 데이터와 저장/복구.
- Player/, Resources/: 영웅 능력, 장비, 이동, Food/Mana.
- Units/, Combat/, Aura/, Pathing/: 병종, 소환, 자동 이동/전투/지원, 오라, 경로.
- UI/, Camera/: 준비/전투/성장/결과 UI, 전선 표시, 카메라.
- Editor/: 씬 준비와 단계별/실제 Play 모드 검증.
